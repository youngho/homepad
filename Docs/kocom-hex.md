# 코콤 RS-485 패킷 프리셋

> **💡 사용 및 편집 안내**:
> - 새 명령을 추가할 때 아래 표에 `| 이름 | 설명 | HEX |` 형식으로 한 줄만 추가하면 유니티에 자동으로 반영됩니다.
> - HEX 값은 `AA 55`로 시작하고 `0D 0D`로 끝나는 21바이트(42글자) 규격입니다.
> - 체크섬(19번째 바이트)이 확실하지 않을 경우 에디터의 **[Tools > Kocom > Validate All Hex Presets]**를 누르면 자동 검증/계산됩니다.
